# 战线 1914 · 比利时战役 v1.1

单文件网页六角格战棋：你指挥协约国，在 64×64 比利时地图上挡住德军 16 回合。纯静态、零依赖、打开即玩，附可视化编辑器。

> v1.1 修掉了「占着全图大部分城镇却判负」的胜利条件，重写 AI，加入守桥/绕要塞/炮兵反制、自动存档、撤销、增援编辑。

## 目录结构

```
.
├── index.html      游戏本体（含内嵌 JSON 数据块）
├── editor.html     编辑器（含同一份数据块作为兜底）
├── gamedata.json   当前数据导出，可在游戏里「载入」
├── .nojekyll       告诉 GitHub Pages 不要用 Jekyll
└── README.md
```

> 两个 HTML 互不依赖，但要**放在同一目录**——编辑器的「从游戏载入」会读取同目录的 `index.html` 同步最新数据。

## 玩法

- **目标**：撑满 16 回合。任一敌军阵营在回合末控制城镇总分达到其阈值（默认德军 10 / 全图 26）即失败。
- **操作**：点己方单位 → 蓝格移动 → 点红框敌军看预览 → 再点一次或按「攻击」。
- **联合进攻**：与目标相邻且本回合未行动的友军会一起参战。
- **炮兵**：射程 3、最小射程 2；远程不受反击但降 1 列（打要塞不降）；被近战突袭防御 ×0.5；炮对炮 +1 列。
- **士气**：0–6，低士气禁攻；本回合没开火则回合末 +1；据守城镇上限 +1。
- **城镇**：战果与兵源来源；兵力按 4 段结算，不是连续血条。
- **存档**：每回合自动存，刷新后顶部出现「已恢复上局」；「重开」清档。
- **快捷键**：`Esc` 取消，空格结束回合，`N` 下一队，`R` 征兵，`U` 撤销移动，`+/-` 缩放，`?` 帮助。

### 规则要点

- 你是协约国，AI 是德军。守住 16 回合，德军累计控制不到 10 分即胜。
- 兵力显示 0–100，但按 4 个「段」离散结算（满编 / 减员 / 残破 / 濒危）。
- 城镇既是战果来源也是兵源产地，要塞额外提供防御加成。
- 布鲁塞尔是 AI 的重点目标（`capital`），但不单独触发即时失败。

## 编辑器

| 页签 | 能改什么 |
|---|---|
| **兵种** | 攻/防/移/射程/兵力/士气/费用，新增或删除兵种，实时看期望伤害 |
| **地图** | 涂地形、放城镇（城镇/要塞/首都）、放部队、平移；新建任意尺寸地图 |
| **势力** | 增删势力，配色、外形、阵营、角色、胜利阈值、回合上限、兵源、集结区 |
| **战斗规则** | CRT、赔率分界、段位、士气档、损失、炮兵修正、征兵、增援 |
| **平衡预览** | 期望伤害矩阵与击杀次数，粗筛超模兵种 |

- 顶部「撤销」或 Ctrl+Z 回退最近 25 步。
- **保存并应用** → 写入浏览器 localStorage → 回游戏刷新即生效。
- 换设备：编辑器 **导出 JSON** → 游戏 **载入** 选择文件。

> 不要用 `file://` 直接双击打开编辑器；那种模式浏览器禁止读取相邻文件。GitHub Pages 是 http 服务，没有这个问题。

## 部署到 GitHub Pages

### 方式一：网页上传（不需要 git）

1. 新建 Public 仓库，比如 `frontline-1914`
2. **Add file → Upload files**，把本目录全部文件拖进去（`index.html`、`editor.html`、`gamedata.json`、`README.md`、`.nojekyll`）
   - `.nojekyll` 是隐藏文件，Windows 在「查看」里勾选「隐藏的项目」
3. **Commit changes**
4. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → Branch **main** / **/(root)** → **Save**
5. 等 1–2 分钟，地址是 `https://<用户名>.github.io/<仓库名>/`

### 方式二：命令行

```bash
git init
git add .
git commit -m "frontline 1914 v1.1"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

然后同上开启 Pages。

### 更新已有站点

把新 `index.html` / `editor.html` / `gamedata.json` / `README.md` 覆盖旧文件，commit，Pages 会自动重建。想保留旧版就先打 tag 或复制到 `archive/`。

## 已知限制

- AI 仍可能在桥头排队；已加多桥/地形成本，但没有渡口预约。
- 只支持一个玩家势力，没有热座。
- 布鲁塞尔 `capital` 只影响 AI 目标，不是即时胜利条件。
- 人类难度未做真人校准；德军阈值可在编辑器里改。
