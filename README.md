# 战线 / FRONT LINE

> 一套跨时代的六角格战棋。
>
> 1914 年的比利时，只是第一场。

《战线》的目标不是复刻某一场战役，而是做一套能装下不同战场、不同时代的战术核心：**同一套移动、战斗、士气与征兵规则，每个战役换一份数据包。**

当前可玩的是 **比利时 1914**。仓库里还有 1943 年的早期原型、1914–1989 的全量设计文档，以及一个可以把任何地图/兵种/规则做成新战役的编辑器。

## 这个项目不止一场战役

- **一套核心，多场战役**：六角格、段位损失、士气、CRT、联合进攻、炮兵、征兵、AI 寻路，这些是共用的。
- **一场战役 = 一份数据**：地图、兵种、势力、城镇、胜负阈值、援军，全部写在 JSON 里；换一套数据就是换一场战役。
- **跨度 1914–1989**：一战西线、二战东线、冷战富尔达走廊，是设计文档里的三个目标时代；不是当前全部已实现。
- **编辑器就是战役工具**：不用改代码，可以画地图、改兵种、设势力、调 CRT、放援军，导出一份新战役数据。

这也是为什么当前版本叫“战线”，而不是“比利时 1914”——比利时是验证核心的第一场，不是终点。

## 当前战役：比利时 1914

- **你**：协约国，38 个单位，据守列日与那慕尔。
- **AI**：德意志帝国，50 个单位（含 1 门列车炮），从东侧进攻。
- **援军**：第 3–6 回合陆续抵达；第 6 回合双方会投入大批援军。
- **地图**：64×64，10 座主要城镇，全图 26 分，开局约 88 个单位。
- **目标**：撑满 16 回合。德军在回合末控制 ≥ **10 分**城镇，你失败。
- **关键点**：默兹河、代勒河上的桥；列日/那慕尔要塞；布鲁塞尔 4 分。
- **特殊单位**：列车炮（攻 8 / 防 6 / 射程 6），本数据未填最小射程，按引擎默认 1 处理。

## 规则速览

### 不是血条，是「段」

兵力显示 0–100，但战斗按 4 段结算：

| 段 | 剩余兵力 | 战力 |
|---|---|---|
| 满编 | 75% 以上 | ×1.00 |
| 减员 | 50% 以上 | ×0.80 |
| 残破 | 25% 以上 | ×0.60 |
| 濒危 | 0% 以上 | ×0.40 |

一次攻击没跨过段位，也会**强制掉一段**。

### 士气

士气 0–6，分高 / 中 / 低 / 溃散：

- 低士气**不能进攻**
- 溃散会强制后撤并追加损失
- 本回合**没有开火**，回合末士气 +1
- 据守城镇/要塞，士气上限 +1

### 音乐

- 内置 BGM《铁幕行军》，循环播放
- 浏览器禁止无交互自动播放：首次点击/按键后才开始
- 右上角「♪」可快速静音/恢复；设置页可调音量（0–100）

### 炮兵与联合进攻

- 射程 3、最小射程 2，被贴脸不能开火
- 远程不受反击，但降 1 列；打要塞不降
- 被近战突袭防御 ×0.5；炮对炮有反炮兵 +1 列
- 与目标相邻、未行动的友军会一起参战；集中 3–4 个师打一个点

## 操作

| 操作 | 说明 |
|---|---|
| 点击己方单位 | 选中，显示可移动格与可攻击目标 |
| 点击蓝格 | 移动 |
| 点击红框敌军 | 查看战斗预览 |
| 再点一次 / 按「攻击」 | 执行攻击 |
| 下一队 | 跳到下一个可行动单位 |
| 撤销 | 撤回本回合最后一次移动 |
| 征兵 | 在据守城镇或后方集结区组建部队 |
| 结束回合 | 交给 AI 行动 |
| 菜单 | 回主菜单 / 设置 / 帮助 |

快捷键：`Esc` 取消，空格结束回合，`N` 下一队，`R` 征兵，`U` 撤销移动，`+/-` 缩放，`?` 帮助。

手机上：单指拖动地图，轻点选中/移动。

## 编辑器：下一场战役从这里开始

`editor.html` 是同一套数据的可视化编辑器：

- 兵种、地图、势力、战斗规则、平衡预览
- 地图页支持**放援军**：选阵营/兵种、设定回合，然后在地图上点或拖；援军不会开局出现，只会在指定回合出现在指定格
- 「保存并应用」写入浏览器本地存储，回游戏刷新即生效
- 换设备：编辑器 **导出 JSON** → 游戏 **载入** 选择文件

## 路线图

这些是目标，不是当前已完成功能：

1. **把 1943 原型升级成完整战役**：更大的地图、完整兵种、AI、胜负条件。
2. **多战役选择**：主菜单「战役」里出现 1914、1943、1944……每份都是独立数据包。
3. **时代规则层**：一战的炮兵/要塞、二战的装甲/反坦克、冷战的导弹/电子战/核门槛。
4. **编辑器战役包**：导出/导入整场战役，而不只是当前地图数据。
5. **热座 / 多人**：同一设备轮流指挥，或异步对战。
6. **迷雾、补给、指挥**：设计文档里的目标系统；当前版本还没有。

## 技术说明

- 单文件 HTML，零依赖：不引 CDN、不用第三方库、不加载外部图片
- 数据驱动：所有数值在 `<script type="application/json" id="GD">` 块里
- 移动端可用：不依赖 `prompt()/confirm()`，触控目标 ≥ 40px
- 存档：`localStorage`，每回合与每次操作自动保存
- BGM 以 base64 内嵌进 `index.html`，不依赖外部音频文件
- 无后端、无账号、无联网

## 目录结构

```
.
├── index.html      当前战役：比利时 1914（含内嵌 JSON 数据块）
├── editor.html     编辑器（含同一份数据块作为兜底）
├── gamedata.json   当前数据导出，可在游戏里「载入」
├── .nojekyll       告诉 GitHub Pages 不要用 Jekyll
└── README.md
```

> 两个 HTML 互不依赖，但要放在同一目录——编辑器的「从游戏载入」会读取同目录的 `index.html`。

## 部署到 GitHub Pages

1. 新建 Public 仓库，比如 `frontline`
2. 把本目录全部文件上传（`index.html`、`editor.html`、`gamedata.json`、`README.md`、`.nojekyll`）
3. 仓库 → **Settings → Pages** → **Deploy from a branch** → **main** / **/(root)** → **Save**
4. 等 1–2 分钟，打开 `https://<用户名>.github.io/<仓库名>/`

更新已有站点时，覆盖 `index.html` / `editor.html` / `gamedata.json` 即可；`CNAME` 不要删。

## 已知限制

- 当前只接入比利时 1914；1943 原型与 1914–1989 设计蓝图在完整交接包里，未接入主菜单。
- AI 仍可能在桥头排队；已加多桥与地形成本，但没有渡口预约。
- 只支持一个玩家势力，没有热座。
- 布鲁塞尔 `capital` 只影响 AI 目标，不是即时胜利条件。
- 人类难度未做真人校准；德军阈值可在编辑器里调。
